# uf2216-aulanexo-guerreostrachanalcoba-miguelangel


este repositorio es para el examen:  aquí  podemos encontrar 4 carpetas principales,que son: administracion,alumnado,direccion,profesorado.
Si accedemos al interior de ellas, podemos ver que cada una de estas 4 carpetas cuenta con 2 subcarpetas dentro y cada una con un readme de ejemplo.
La carpeta administración  aparte de tener dos subcarpetas, en facturas encontramos la carpeta provedores.
Aparte, tenemos una carpeta de metadatos, donde se ve una plantilla de metadatos.


Para localizar una factura, iriamos a la carpeta administración y dentro a la de facturas.
Para localizar un examen,iremos a la carpeta profesorado y en funcción de si son examenes de un profesor antiguo o actual entramos en esa carpeta y hay tenemos la carpeta exámenes.
Para localizar una programación, iriamos a la carpeta direccion,dentro a coordinación y dentro buscamos.


Búsqueda facetada es una búsqueda usando varios filtros ejemplo amazon.
busqueda full-text es buscar todo a cholón.
